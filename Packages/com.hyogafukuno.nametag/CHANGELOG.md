# Changelog

## [1.0.2] - 2026-10-02

### Fixed
- git pull などで設定ファイルが外部から更新された場合に、エディタが古い内容で上書き保存してしまう問題を修正しました（設定ファイルの更新を検知して再読み込みします）。
- 設定変更後もインスペクタの名前タグ欄が古い表示のまま残る問題を修正しました。
- マージなどで同じアセットの割り当てが重複していると、名前タグの変更が反映されない問題を修正しました。
- 削除した直後のアセットの割り当てが「存在しない」と判定されず、一覧の表示や削除ボタンが機能しない問題を修正しました。
- Names リストの追加・削除・並べ替えが保存されない場合がある問題を修正しました。
- 複数選択で値が混在しているとき、先頭のアセットと同じ名前を選ぶと変更が反映されない場合がある問題を修正しました。
- 空白のみの名前が選択肢に表示される問題を修正しました。

## [1.0.1] - 2026-10-01

### Added
- パッケージに MIT ライセンス（LICENSE.md）を同梱しました。

## [1.0.0] - 2026-10-01

### Added
- Project Settings > NameTag Settings で名前タグに使う名前を登録できるようにしました。
- インスペクタ下部（Asset Labels の上）に名前タグを割り当てるプルダウンを追加しました。
- Project ウィンドウのアイコン右下に、白い角丸背景付きで名前タグを表示するようにしました。
- ファイル自身にタグがない場合は、最も近い親フォルダのタグを表示するようにしました（ファイル自身のタグが優先）。
